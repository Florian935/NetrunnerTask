Compact HUD stat readout — coloured dot + label + value. Used in the top bar / profile HUD.

```jsx
<StatChip kind="level" label="Level" value="13" />
<StatChip kind="credits" label="Credits" value="4,820" />
<StatChip kind="streak" label="Streak" value="9d" layout="inline" />
```

Kinds: `xp` `credits` `rep` `level` `streak` `neutral`. `layout`: `stack` (default) or `inline`.
