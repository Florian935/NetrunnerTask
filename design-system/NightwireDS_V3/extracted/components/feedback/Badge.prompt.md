**Badge** — tiny status marker (NEW, HOT, BETA, a count, an online dot label). Not interactive — use Tag for removable chips.

```jsx
<Badge tone="magenta" solid glow>HOT</Badge>
<Badge tone="mint">ONLINE</Badge>
```

Tones: cyan, magenta, mint, violet, amber, red, neutral. `solid` fills; `glow` adds neon.
