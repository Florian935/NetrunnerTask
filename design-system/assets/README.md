# Assets

**No logo or brand mark was supplied.** Per design-system policy, no logo was invented or reconstructed.

The brand is rendered as a **type-only wordmark** using the display font (Chakra Petch) with a monospace terminal prefix:

```
>_ NETRUNNER·TASK
```

See the `Wordmark` component in `ui_kits/app/chrome.jsx` and the homepage `thumbnail.html` for the canonical treatment. Cyan (`--nt-cyan-500`) is used as the accent on the "·TASK" segment / caret with a soft glow.

**Icons** are loaded from the [Lucide](https://lucide.dev) CDN (`lucide@0.454.0`), not stored here — see the Iconography section of the root `readme.md`.

> **Ask:** if you have a real logo (SVG preferred), drop it in `assets/logo.svg` and we'll wire it into the wordmark, HUD bar, jack-in screen, and thumbnail.
